## 📌 Giới thiệu

Repository này được tạo ra nhằm mục đích:
* **Lưu trữ & Quản lý:** Theo dõi tiến trình học tập và lưu trữ bài tập các môn học tại NTU.
* **Ôn tập & Tra cứu:** Luyện tập sử dụng Git và Github cũng như dễ dàng xem lại mã nguồn, cấu trúc dữ liệu và thuật toán khi cần.
* **Chia sẻ:** Làm tài liệu tham khảo cho các bạn sinh viên NTU khóa sau.
